# Saket Kumar Mahato — Personal Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Customize before publishing
- Replace the GitHub, LinkedIn, and LeetCode placeholders with your real profile URLs. Update the Future section as your analytics, data engineering, business, and startup interests evolve.
- Replace illustrative project graphics with screenshots of your actual projects when available.
- Review all resume details and contact information before publishing.
- Google Fonts are loaded online; fallback fonts are provided.

## Accessibility and behavior
- Responsive mobile navigation with Escape-key support.
- Skip-to-content link, visible keyboard focus, descriptive image labels, and reduced-motion support.
- Scroll-reveal effects are progressively enhanced; content remains visible if JavaScript or IntersectionObserver is unavailable.
- Project cards are keyboard-focusable. The decorative project visuals are explicitly labelled as illustrations.

## Deploy
Deploy this folder as a static site using GitHub Pages, Netlify, or Vercel. No backend is required.
